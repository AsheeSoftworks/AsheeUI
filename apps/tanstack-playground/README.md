# AsheeUI TanStack Start playground

One of the three playground applications that consume AsheeUI the way a real
project does. It is a full-stack application built on TanStack Start with
TanStack Router, and its end-to-end test is the proof that the library works
there.

## What it proves

- The library renders in a full-stack framework's route tree, inside the
  provider the root route's document shell supplies.
- The route is server-rendered in a browserless environment, parsed, and checked
  against the same gallery contract the other two playgrounds assert, so the
  served markup is verified rather than assumed.
- The route works in a browser once mounted: the interactions a consumer performs
  (paging, tabs, accordion, dialog, tooltip) all behave.
- TanStack Router's own `Link` can be substituted into every component that
  renders a link, which keeps the router's client-side navigation inside the
  library's components.

## Running it

```bash
pnpm --filter @asheeui/tanstack-playground dev      # development server
pnpm --filter @asheeui/tanstack-playground build    # type check, then build
pnpm --filter @asheeui/tanstack-playground test     # server and browser tests
```

`src/routeTree.gen.ts` is generated by the framework's Vite plugin during a
build; it is committed, as TanStack Router expects, and excluded from the
repository's linter.

The gallery itself lives in `packages/e2e-gallery`; this application contributes
only what makes it a TanStack Start application.
